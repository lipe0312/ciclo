# Segurança

Projeto pessoal, mas leve a sério: ele lida com dados de saúde de quem o hospeda.

- Encontrou uma falha? Abra um **security advisory privado** em *Security → Report a vulnerability* neste repositório, sem issue pública.
- Nunca inclua dados reais (peso, dor, comida, vídeos) em issues ou PRs.
- Modelo de ameaças e defesas: [`docs/03-seguranca.md`](docs/03-seguranca.md).
